# 애니 오디오 브리지 (Chrome 확장)

이 확장은 사이트 자막이나 화면의 영어 하드자막을 읽지 않습니다. `AnimeAudioCaptioner.exe`와 로컬 주소 `127.0.0.1`로만 연결합니다.

1. 먼저 `AnimeAudioCaptioner.exe`를 실행합니다.
2. Chrome에서 gogoanime 영상을 평소처럼 재생합니다.
3. 이 확장 아이콘을 한 번 누릅니다.
4. `탭 소리 입력 확인됨` 표시 뒤, EXE가 인식한 음성이 한국어로 영상 위에 표시됩니다.

Chrome의 보안 규칙 때문에 새 탭에서 시작할 때 아이콘을 한 번 누르는 동작은 필요합니다. 같은 탭에서 다음 에피소드로 이동하는 경우에는 다시 설정할 필요가 없습니다.

기존 `애니 자막 뷰어 1.0.1`은 삭제하지 말고 사용 중지만 하세요. 두 확장을 동시에 켜면 자막 UI가 겹칠 수 있습니다.
